## Measurement Method

- Pipeline duration: use GitHub Actions run timings.
- Success rate: successful completed runs divided by all
  completed runs in the period; record cancellations separately.
- Merge-to-live lead time: time from merge to verified deployment.
- Recovery time: time from deployment failure to restored service.
- Record sample counts and links supporting each result.
