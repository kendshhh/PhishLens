## Actual local-model results

Command: `python scripts/benchmark_ai.py --models local --repeats 1 --pause 0`.
Checkpoint revision: `310a5602280486e01dd60e37230980cfcc327b41`.
Cases: `synthetic-v1`, 16 phishing, 16 legitimate, and 8 spam.
Full machine/run summary: [JSON evidence](evidence/ai-local-2026-10-18.json).

| Measurement | Observed result |
| --- | --- |
| Calls | 40 successful, 0 runtime errors. |
| Binary accuracy | 24/40 (60%); spam counted as non-phishing. |
| Phishing recall | 12/16 (75%); 4 missed phishing cases. |
| Phishing precision | 12/24 (50%). |
| False-positive rate | 12/24 non-phishing cases (50%). |
| False positives | 4 legitimate examples and all 8 spam examples. |
| Missed phishing cases | Gift-card impersonation, malicious macro instructions, campus credential request, and a malicious request at the end of a long bulletin. |
| Cold inference | 65.90 seconds on the tested Windows development machine. |
| Peak process RSS | 578.87 MiB for the benchmark process. |
| Warm latency | Median 0.0315 seconds; p95 0.0661 seconds. |

The long-bulletin attack was missed even though all three windows were processed.
Window coverage therefore does not establish detection quality. These results
are a small development regression suite, not a held-out accuracy study. Do not
promote the local model on the basis of successful loading or high softmax scores.
